# Homelab

Коллекция Docker Compose-конфигураций, установочных скриптов и заметок для домашней лаборатории и VPS. Репозиторий охватывает VPN и прокси, медиасерверы, умный дом, видеонаблюдение, файловые сервисы и инструменты администрирования.

Каждый каталог содержит отдельный сервис, набор материалов или несколько вариантов развертывания. Общего Compose-файла и единой команды установки всего homelab нет.

## Как пользоваться

1. Выберите каталог нужного сервиса и прочитайте его README или инструкцию, если она есть.
2. Проверьте конфигурацию: пути к данным, порты, имена интерфейсов, адреса серверов, права доступа и переменные окружения зависят от вашей машины.
3. Подготовьте каталоги для постоянных данных и требуемые параметры окружения. Например, стек `media_server` использует `PUID`, `PGID` и `TZ`.
4. Запустите выбранный сервис и проверьте его состояние и логи.

Для Docker-сценариев нужны Docker Engine и плагин Docker Compose. Пример запуска отдельного Jellyfin из корня репозитория после адаптации конфигурации:

```bash
cd jellyfin
# Проверить корректность Compose-файла без вывода его содержимого.
docker compose config --quiet
# Запустить сервис в фоновом режиме.
docker compose up -d
# Проверить состояние и последние логи.
docker compose ps
docker compose logs --tail=100
```

Команды выполняются в каталоге выбранного сервиса. Если там несколько вариантов конфигурации, укажите нужный файл через `docker compose -f <имя-файла> ...`. Для установочных скриптов VPN и других компонентов используйте инструкции соответствующего каталога.

## Настройка окружения

- Многие файлы отражают конкретную домашнюю инфраструктуру: перед запуском адаптируйте bind mounts, устройства, сетевые настройки и опубликованные порты.
- Файлы `.env` и параметры отдельных проектов имеют разное назначение. Не предполагается, что один набор переменных подходит всем сервисам. Токены, пароли, cookies и приватные ключи храните локально и не добавляйте в Git.
- Отдельный `jellyfin` и стек `media_server` содержат Jellyfin: при одновременном запуске проверьте пересечения портов и каталогов данных.
- Скрипты настройки VPN могут менять системную маршрутизацию, firewall и службы. Их особенности описаны в [README WireGuard](wirequard/readme.md) и локальных инструкциях.
- Вложенные сторонние проекты имеют собственные зависимости и лицензии. Условия использования смотрите в их README и файлах лицензий.

Материалы служат заготовками для настройки и экспериментов. Наличие конфигурации в репозитории не означает, что сервис уже развернут или проверен на вашей системе.
